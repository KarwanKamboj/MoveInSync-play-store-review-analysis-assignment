7. Repeatable Python Pipeline Architecture for Periodic Audits

Designed for zero-touch monthly/quarterly FDE execution with strict separation between immutable raw snapshots (data/raw/) and processed outputs (data/processed/, reports/figures/):

# 1. Offline Deterministic Reproduction (~5 sec)
python run_pipeline.py --analyze

# 2. Live Collection + Full Re-Analysis
python run_pipeline.py --all \
  --primary-start 2025-09-01 \
  --primary-end 2026-09-30
Key Engineering Safeguards Built In:
  • Multi-Cohort Verification: Unfiltered Newest stream cross-checked against 1★–5★ stratified streams + Indian multilingual passes (hi, kn, ta, te).
  • Primary-Key Deduplication: Deduplicates by reviewId (`8,808` raw → `5,008` unique).
  • Strict Window Quarantine: Automatically recalculates Most Recent 90d vs. Preceding 90d relative to --primary-end while quarantining older history.
